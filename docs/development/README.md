# ATM 개발 준비 문서

> **현재 구현:** ATM 앱 v1.0.0과 제품 자동 시험을 완료했다. 실행은 루트의 [README](../../README.md), 현재 상태는 [구현 현황](../results/구현현황.md), 실제 시험 결과는 [제품 시험 결과](../results/테스트결과.md)를 참조한다. 아래 본문은 구현 이전의 설계 기준 기록이다.

기준일: 2026-11-18 / 통합 설계 v3.0.0 / 작성자: 박교범(2023243047)

11월 16일 피드백을 반영한 상세설계서를 실제 구현 작업으로 연결하기 위한 자료이다. 제품 구현 및 제품 시험은 아직 수행하지 않았다. 아래의 환경·형식·자료 유지 규칙은 원문 미정 사항에 대한 **개발 기준안**이다.

1. [개발환경과 아키텍처](01_개발환경_아키텍처.md)
2. [메소드 인터페이스 계약](02_인터페이스_계약.md)
3. [데이터·검증 규칙](03_데이터설계.md)
4. [시험 계획과 37개 시험 사례](04_테스트계획.md)
5. [구현 작업과 완료 기준](05_구현계획_완료기준.md)
6. [설계 결정과 변경 관리](06_설계결정_변경관리.md)
7. [피드백 반영 및 요구사항 추적](07_피드백_추적표.md)
8. [수동 실행 결과 기록 양식](08_수동검증_기록양식.md)

기계가 읽는 자료는 `data/accounts.schema.json`, `data/accounts.seed.json`, `test_cases.json`, `interface_catalog.json`에 있다. 가상 데이터만 포함한다. 수정 가능한 UML은 `../다이어그램/최종보완/`의 SVG·PlantUML을 사용한다. 원본 VPP는 보존되어 있으며 새 그림을 VPP 내부에 반영하지는 않았다.

개발 시작은 01→03→02→05 순서로 읽고, 요구사항별 시험을 구현할 때 04를 참조한다. 원문과 다른 보완 결정을 변경할 경우 06의 변경 기록을 먼저 남긴다.

설계 자료 재생성 도구는 `tools/docs/build_diagrams.py`, `tools/docs/build_dev_docs.py`, `tools/docs/build_documents.py`이다. 현재 Word 가이드는 `python tools/docs/build_project_guide.py`로 생성한다. 문서 생성 의존성은 `tools/docs/requirements.txt`에 있으며 제품 실행 의존성과 별개이다. 위 경로와 명령은 프로젝트 루트 기준이다.
